# 동네 놀이터와 주변 풍경 — 3D로 보기

폰으로 찍은 영상 하나에서 **동네 놀이터와 주변 풍경**의 3차원 장면(가우시안 스플랫)을 만들어 웹에 올린 것입니다.
브라우저에서 마우스·손가락으로 돌려 볼 수 있고, 서버도 빌드 과정도 없이 파일 두 개로 돕니다.

## 바로 보기

**https://jubyeong-kim.github.io/room3d-view/**

- 페이지가 뜨면 13MB짜리 장면 파일을 받고, 다 받으면 화면에 놀이터와 주변 풍경이 나타납니다.
- 회선이 느리면 첫 화면까지 30초까지 걸릴 수 있습니다. **비어 보여도 고장이 아니라 받는 중입니다.**
- 마우스/손가락으로 **회전·확대·이동**이 됩니다.

## 📱 폰에서 볼 때

- **장면을 보려면 위 주소를 그대로 여세요.** 그러면 3D 화면이 뜹니다.
- 주소 뒤에 `/scene.sog` 를 붙이면(예: `.../room3d-view/scene.sog`) **화면이 안 뜨고 파일만 다운로드**됩니다.
  이건 고장이 아닙니다 — `scene.sog` 는 그림이 아니라 장면 데이터(이진 파일)라서 폰이 "볼 것"이 없어 그냥 내려받습니다.
  이 주소는 "파일이 실제로 받아지는지" 확인할 때만 쓰고, **눈으로 보는 건 항상 맨 위 주소**입니다.

## 파일 구성

| 파일 | 크기 | 하는 일 |
|---|---|---|
| `index.html` | 7.5KB | 장면을 불러와 화면에 그리는 뷰어 |
| `scene.sog` | 약 12.9MB (13,507,531 byte) | 놀이터와 주변 풍경을 이루는 알갱이 **2,681,193개** |

- 둘이 **같은 폴더**에 있어야 합니다.
- 뷰어는 `index.html` 맨 위 한 줄(`SPLAT_FILE = "scene.sog"`)만 바꾸면 다른 장면 파일도 띄웁니다.

## 만든 순서

```
영상 → 사진 24장 → 점 + 카메라 위치 → 알갱이(.ply) → 줄인 파일(.sog) → 깃허브 주소
```

1. **복원** — 폰 영상에서 사진 24장을 고르게 뽑아, `facebook/map-anything-apache` 모델(코랩 무료 T4 GPU)로 놀이터와 주변 풍경의 3차원 점과 카메라 위치를 얻음. 멀리 튄 점은 버림.
2. **알갱이로 변환** — 점 하나를 부피·색·투명도를 가진 가우시안 스플랫으로 바꿔 INRIA 형식 `.ply` 로 저장. (Y축이 뒤집혀 있어 y·z 부호를 뒤집음)
3. **줄이기** — 217MB급 `.ply` 를 `.sog` 로 압축(약 14배). 깃허브 파일 한도(100MB) 안으로 들어옴.
4. **띄우기** — three.js + Spark 로 `index.html` 뷰어 작성.
5. **공개** — 이 저장소를 public 으로 만들고 GitHub Pages 켬 → 위 주소가 열림.

## 파일만 갈아 끼우기

장면을 다시 찍었으면 **`scene.sog` 파일만 새것으로 바꿔 올리면** 됩니다.
`index.html` 과 페이지 설정은 그대로 두면 주소도 그대로 유지됩니다.

## 잘 됐는지 확인표

| 확인할 것 | 판단 방법 |
|---|---|
| 첫 화면까지 몇 초? | 화면에 찍힌 시간을 봄. 느린 회선은 30초까지 정상 |
| 크게 돌려도 앞뒤가 안 뒤집히나 | 손가락으로 여러 번 크게 회전 |
| 부드럽게 도나 | 뚝뚝 끊기면 알갱이 수를 줄일 신호 |
| 파일이 받아지나 | 주소 뒤 `/scene.sog` — 다운로드되면 정상 |
